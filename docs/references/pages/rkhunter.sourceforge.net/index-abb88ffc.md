# The Rootkit Hunter project

## Welcome to the Rootkit Hunter project site

### Downloading and running Rootkit Hunter

To run Rootkit Hunter please install or upgrade to [Rootkit Hunter version 1.4.6](https://sourceforge.net/projects/rkhunter/files/rkhunter/1.4.6/), and read the [README](https://sourceforge.net/p/rkhunter/rkh_code/ci/master/tree/files/README) file.

- If you have any questions about what Rootkit Hunter reports, or if you encounter a runtime or configuration problem, then please first consult the [Rootkit Hunter installation tutorial](https://sourceforge.net/p/rkhunter/wiki/index/) (if applicable), the [Rootkit Hunter FAQ](https://sourceforge.net/p/rkhunter/rkh_code/ci/master/tree/files/FAQ) and the [rkhunter-users mailing list archives.](https://sourceforge.net/p/rkhunter/mailman/rkhunter-users/)
- If your question is not answered in the FAQ or the mailing list archives, please join (subscribe) to the [rkhunter-users mailing list](https://lists.sourceforge.net/mailman/listinfo/rkhunter-users) and ask.
- If you would like to be kept informed of updates we also have a (very) low volume [rkhunter-announce mailing list](https://lists.sourceforge.net/mailman/listinfo/rkhunter-announce).
- If you would like to report a bug, downstream (package maintainer) changes or supply a patch, then please use the [Rootkit Hunter bug tracker](https://sourceforge.net/p/rkhunter/_list/tickets). If unsure, then please first check on the [rkhunter-users mailing list](https://lists.sourceforge.net/mailman/listinfo/rkhunter-users).

### Rootkit Hunter release 1.4.6 (February 20th 2018)

The Rootkit Hunter project team is pleased to announce the release of version 1.4.6.
For details please see the [CHANGELOG](https://sourceforge.net/p/rkhunter/rkh_code/ci/master/tree/files/CHANGELOG) file.
Rootkit Hunter release 1.4.6 obsoletes all previous releases.

### About the project

In 2006 the Rootkit Hunter initial developer M. Boelen handed over development. The development team, comprising of two developers, has been releasing Rootkit Hunter since version 1.2.9. The rkhunter [dot] sourceforge [dot] net website is the official home for the Rootkit Hunter project.
