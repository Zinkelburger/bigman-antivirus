## Like YARA, but better

YARA-X is a re-incarnation of [YARA](https://virustotal.github.io/yara), with a focus on user-friendliness, performance and safety. [Why it's better?](https://virustotal.github.io/yara-x/docs/intro/yara-x-vs-yara/)

## 99% rule compatible

Most of your YARA rules will work with YARA-X without any changes. If not, it should be for the better. Learn [more](https://virustotal.github.io/yara-x/docs/writing_rules/differences-with-yara).

## Easy integration

YARA-X is written in Rust, but we provide APIs for [C/C++](https://virustotal.github.io/yara-x/docs/api/c/c-/), [Python](https://virustotal.github.io/yara-x/docs/api/python) and [Go](https://virustotal.github.io/yara-x/docs/api/go).
