### Details

https://github.com/linuxmint/cinnamon-screensaver/issues/354

Pressing a certain key in caribou's on-screen keyboard can crash caribou on versions of xorg-server containing the fix for CVE-2020-25712.

https://gitlab.freedesktop.org/xorg/xserver/-/commit/87c64fc5b0db9f62f4e361444f4b60501ebf67b9

Cinnamon uses caribou's on-screen keyboard in the lock screen, and crashing caribou crashes the lock screen, thus bypassing the password prompt and granting arbitrary physical access to unattended login sessions.

The cinnamon developers have submitted a MR to caribou which fixes the crash:https://gitlab.gnome.org/GNOME/caribou/-/merge_requests/3

No CVE has been assigned yet, I think.
