# Ubuntu Vulnerability Data

https://github.com/canonical/ubuntu-security-notices#ubuntu-vulnerability-data

This repository contains Ubuntu Vulnerability Data in 3 different JSON formats:

-

The USN/LSN JSON format as generated by the Ubuntu Security Team, we do not advise using this format as it can be changed at any time to fit the team's needs.

-

OSV JSON format, for more information see our [OSV documentation](https://documentation.ubuntu.com/security/docs/security-updates/osv/)

-

OpenVEX JSON format, for more information see our [VEX documentation](https://documentation.ubuntu.com/security/docs/security-updates/vex/)
