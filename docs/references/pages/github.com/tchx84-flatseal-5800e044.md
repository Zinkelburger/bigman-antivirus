# Flatseal https://github.com/tchx84/Flatseal/workflows/CI/badge.svg

https://github.com/tchx84/Flatseal#flatseal-

https://github.com/tchx84/Flatseal/blob/master/data/icons/com.github.tchx84.Flatseal.svg

Flatseal is a graphical utility to review and modify permissions from your [Flatpak](https://flatpak.org/) applications.

## Usage

https://github.com/tchx84/Flatseal#usage

Simply launch Flatseal, select an application and modify its permissions. Restart the application after making the changes. If anything goes wrong just press the reset button.

For more details please visit the [documentation](https://github.com/tchx84/Flatseal/blob/master/DOCUMENTATION.md) page.

## Get it

https://github.com/tchx84/Flatseal#get-it

https://flathub.org/apps/details/com.github.tchx84.Flatseal

## Build it yourself

https://github.com/tchx84/Flatseal#build-it-yourself

```
git clone https://github.com/tchx84/Flatseal.git
cd Flatseal
flatpak --user install org.gnome.{Platform,Sdk}//51
flatpak-builder --user --force-clean --install build com.github.tchx84.Flatseal.json
flatpak --user run --branch=master com.github.tchx84.Flatseal

```

Or just use [Builder](https://flathub.org/apps/details/org.gnome.Builder)
