# RustSec Crates 🦀🛡️📦

https://github.com/rustsec/rustsec#rustsec-crates-️

The RustSec Advisory Database is a repository of security advisories filed against Rust crates published via [crates.io](https://crates.io).

The advisory database itself can be found at:

https://github.com/RustSec/advisory-db

## About this repository

https://github.com/rustsec/rustsec#about-this-repository

This repository contains a Cargo Workspace with all of the crates maintained by the RustSec project:

| Name  | Description  | Crate  | Documentation  | Build

| [cargo‑audit](https://github.com/RustSec/rustsec/tree/main/cargo-audit)  | Audit Cargo.lock against the advisory DB  | https://crates.io/crates/cargo-audit  | https://docs.rs/cargo-audit  | https://github.com/RustSec/rustsec/actions/workflows/cargo-audit.yml

| [cargo‑lock](https://github.com/RustSec/rustsec/tree/main/cargo-lock)  | Self-contained Cargo.lock parser  | https://crates.io/crates/cargo-lock  | https://docs.rs/cargo-lock  | https://github.com/RustSec/rustsec/actions/workflows/cargo-lock.yml

| [cvss](https://github.com/RustSec/rustsec/tree/main/cvss)  | Common Vulnerability Scoring System  | https://crates.io/crates/cvss  | https://docs.rs/cvss  | https://github.com/RustSec/rustsec/actions/workflows/cvss.yml

| [platforms](https://github.com/RustSec/rustsec/tree/main/platforms)  | Rust platform registry  | https://crates.io/crates/platforms  | https://docs.rs/platforms  | https://github.com/RustSec/rustsec/actions/workflows/platforms.yml

| [rustsec](https://github.com/RustSec/rustsec/tree/main/rustsec)  | Advisory DB client library  | https://crates.io/crates/rustsec  | https://docs.rs/rustsec  | https://github.com/RustSec/rustsec/actions/workflows/rustsec.yml

| [rustsec‑admin](https://github.com/RustSec/rustsec/tree/main/admin)  | Linter and web site generator  | https://crates.io/crates/rustsec-admin  | https://docs.rs/rustsec-admin  | https://github.com/RustSec/rustsec/actions/workflows/admin.yml
