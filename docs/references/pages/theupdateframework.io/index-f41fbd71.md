# The Update Framework

A framework for securing software update systems

[Learn More](https://theupdateframework.io/docs/overview/) [Get started](https://theupdateframework.io/docs/getting-started/)

The Update Framework (TUF) maintains the security of software update systems, providing protection even against attackers that compromise the repository or signing keys. TUF provides a flexible framework and [specification](https://theupdateframework.io/specification/latest) that developers can adopt into any software update system.
